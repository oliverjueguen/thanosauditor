# Test plan and results (report section 8)

Every requirement has at least one test. The **automated** tests run with
`pytest -q` (162 tests, offline and deterministic; also in the GitHub CI on Linux and
Windows). The **manual** tests were run on the real product on the date shown; those
that depend on an environment that could not be repeated in P3 are marked as pending.

Overall result of the last run (2026-10-13): **162 passed** on Python 3.14 (development
machine, with the `dev` and `auditor` extras); in clean `python:3.10-slim` and
`python:3.12-slim` containers with the `dev` extra: **155 passed, 7 skipped** (the 7 Claude SDK tests); `ruff`,
`bandit` and `pip-audit` with no findings.

## Tests that failed and how they were fixed

| ID | What failed | Cause | Fix |
|---|---|---|---|
| F-1 | On a clean install, `pytest -q` ran no tests | Starlette ≥ 1.x uses `httpx2` in its TestClient and it was not declared | `httpx`/`httpx2` in the `dev` extra and `constraints.txt` with tested versions (PR-24) |
| F-2 | A malformed JSON uploaded to the panel (e.g. `"artifacts": 5`) left it permanently in error 500 | Types were not validated and the invalid file was saved | Strict `validate_bundle`; the store skips corrupt files; size limits (PR-26) |
| F-3 | `diff_manifests` returned 2 of 7 real binaries | The key was only the SXS package (with trailing hash) | Key (normalized package without version or hash, DLL) (PR-06) |
| F-4 | `claude login` did not exist | The real command is `claude auth login` and the CLI ships inside the SDK | `python -m thanos.auditor.cli login/status` (PR-29) |
| F-5 | The auditor was left with 14 active tools and `bypassPermissions` (one of them gave a shell); it also failed as root | SDK configuration based on a deny list | `tools=[]`, `permission_mode="dontAsk"`, no MCP or settings (PR-16, PR-25). Verified as root in `python:3.10-slim`: the old configuration refused to start; the new one only asks to log in |
| F-6 | Ghidra did not start and, later, took more than 12 min with `upnphost.dll` | There was only a JRE; Ghidra loaded every dependent DLL from System32 | Configurable JDK (`java_home`) and `-loader-loadLocalLibraries false` (PR-13: 28 s) |
| F-7 | `msasn1.dll` showed up with a "truncated" diff by names | Unique names were counted instead of the full list | Counts over the full list |

## How to run the tests

```bash
pip install -e ".[dev,auditor]" -c constraints.txt
pytest -q                      # 162 tests (with only ".[dev]": 155 + 7 skipped, the Claude SDK ones)
ruff check .                   # lint
pip-audit -r requirements.txt  # known vulnerabilities
```
